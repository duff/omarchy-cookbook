# Omarchy cookbook

This is duff's public cookbook in the omarchy-kitchen format. Load the `omarchy-kitchen` skill before changing anything here:

- `format.md` is the recipe format.
- `publish.md` has the privacy rules.

Recipes come from the weekly review in the owner's private repo, and only after the owner has said yes to each one. This repo never names that private repo.

Before every commit, run:

```bash
~/.local/share/omarchy-kitchen/bin/kitchen check .
~/.local/share/omarchy-kitchen/bin/kitchen scan --local --cookbook .
```
